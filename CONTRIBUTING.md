# Contributing

## Tooling

- Package manager: npm only
- Format: `npm run format`
- Lint: `npm run lint`
- Types: `npm run check`
- Unit: `npm run test:unit -- --run`

## Commits

Keep messages short and focused on why. Do not add Cursor co-author trailers.

## UI

Use Wash UI recipes and hard tokens. Run Svelte MCP svelte-autofixer on `.svelte` edits. No daisyUI-as-primary kit; Wash ships the gallery classes.
